## Заметки

- установка "cargo install sqlx-cli" для миграций
- миграции: "sqlx migrate add -r foundation" (up, down)
- чтоб пропустить тест нужно добавить метку: #[ignore]
- Проблема: OnceCell создает клиент один раз для всех тестов. Но каждый тест запускается в своем
  runtime. Когда первый тест завершается, его runtime может быть уничтожен, но Client (который внутри
  содержит свой runtime) остается в статической переменной.
  Когда второй тест вызывает get_test_server().await, он получает уже существующий клиент, но его
  внутренний runtime уже мог быть уничтожен после завершения первого теста.
- Copy-семантика работает для типов размер которых известен в стеке и типов у которых реализован trait Copy, и которые
  состоят из св-в которые тоже известны. Для других будет move-семантика. Но перемещение в др. блок не сработает.
- Cargo.toml - файл манифеста написанный разработчиком, описание зависимостей в широком смысле.
- Cargo.lock - содержит точную информацию о зависимостях, какая ревизия была использована для всех этих зависимостей, не
  должен ред-ся в ручную.
- Размещение файла с именем build.rs в корне пакета заставит Cargo скомпилировать этот скрипт и выполнить его
  непосредственно перед сборкой пакета.
- Cargo не очищает и не сбрасывает OUT_DIR между сборками.
